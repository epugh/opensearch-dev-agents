Miscellaneous tooling for using AI agents to help with OpenSearch development

## What's here

- `prompts/maintainer-report.md` — report on repo maintainers
- `prompts/missing-members-report.md` — find maintainers missing org membership
- `prompts/orphan-repos-report.md` — find repos with no active maintainers
- `prompts/flaky-test-report.md` — round up flaky test investigations
- `prompts/srw-activity.md` — Search Relevance Workbench contributor activity report
- `prompts/search-tag-rfc-report.md` — find and triage Search TAG-relevant RFCs org-wide
